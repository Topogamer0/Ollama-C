Detailed Description

A small JSON API for free-form data.

Free-form data (options, format schemas, tool definitions, tool call arguments, model info, ...) is represented as JSON, like the dicts accepted and returned by the Python library.

Ownership rules:

  • Values created by the application (the constructors, ollama_json_parse(), ollama_json_copy(), ollama_tool_new()) are released with ollama_json_free(), unless they have been inserted into a container.
  • ollama_json_append() and ollama_json_set() take ownership of the value they insert, even when they fail.
  • The accessors return pointers into the value they are called on: they stay valid until that value is freed or the member is replaced.
  • Values reachable from a response (json fields, tool call arguments, ...) belong to the response: never free them, and copy them with ollama_json_copy() to keep them longer.
  • Every function accepts NULL where a value is expected and handles it as described below, so calls can be chained without checking each result.

Numbers keep 64-bit integers exact: integers parsed from text or created with ollama_json_int() are stored both as int64_t and as double.

ollama_json_t *options = ollama_json_object();
ollama_json_set_number(options, "temperature", 0.2);
ollama_json_set_int(options, "num_ctx", 8192);
ollama_chat_request_t req = {.model = "gemma3", .messages = msgs, .messages_count = n, .options = options};
// ... ollama_chat(client, &req, &res) ...
ollama_json_free(options);

◆ ollama_json_parse()

ollama_json_t * ollama_json_parse ( const char *  text)

Parses a NUL-terminated JSON document.

The whole text must be a single JSON value, optionally surrounded by whitespace. Integers that fit in 64 bits are kept exact; other numbers are converted to double, whatever the C locale. Duplicate object keys are kept (ollama_json_size() counts them) and ollama_json_get() returns the last one. Escaped lone surrogates become U+FFFD. Values nested more than 512 deep are rejected; the innermost value counts, so at most 511 levels of non-empty arrays or objects (512 when the innermost one is empty).

Parameters
[in]textthe JSON text, or NULL
Returns
A new value to release with ollama_json_free(), or NULL if text is NULL or not valid JSON, or if memory runs out.

◆ ollama_json_stringify()

char * ollama_json_stringify ( const ollama_json_t *  value)

Serializes a value to compact JSON text.

No whitespace is added and object members keep their order. Integers are written exactly, other numbers with up to 17 significant digits (enough to read the same double back) and '.' as decimal point whatever the C locale; NaN and infinities become null. Quotes, backslashes and control characters are escaped; other bytes, such as UTF-8 sequences, are copied as they are.

Parameters
[in]valuethe value; NULL is serialized as "null"
Returns
A new NUL-terminated string to release with ollama_free(), or NULL if memory runs out.

◆ ollama_json_free()

void ollama_json_free ( ollama_json_t *  value)

Releases a value created by the application, with everything it contains.

Only for the values owned by the application: those returned by the constructors, ollama_json_parse(), ollama_json_copy() and ollama_tool_new(). Never free a value that has been inserted into a container (the container frees it) or that belongs to a response.

Parameters
[in]valuethe value to release; NULL is ignored
