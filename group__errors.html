Detailed Description

Status codes and error details.

The functions that return an ollama_status_t, such as all the API calls, return OLLAMA_OK (0) on success, or the code of the error. The functions that return a pointer report a failure with NULL; those that take neither a client nor a stream (ollama_client_new(), the JSON functions, the helpers) record no error details. Where ollama-python raises an exception, Ollama-C returns the matching code and keeps the details (message and HTTP status code) in an ollama_error_t:

  • ollama_last_error() for the calls that take a client, including the errors of the *_stream functions themselves;
  • ollama_stream_error() for the errors that end a stream while its parts are read.
if (ollama_chat(client, &req, &res) != OLLAMA_OK) {
const ollama_error_t *err = ollama_last_error(client);
if (err->code == OLLAMA_ERROR_RESPONSE && err->status_code == 404)
fprintf(stderr, "model not found: %s\n", err->message);
}

◆ ollama_status_t

enum ollama_status_t

Result of a call: OLLAMA_OK or the code of the error.

Enumerator
OLLAMA_OK 

Success.

OLLAMA_ERROR_REQUEST 

Invalid arguments or settings, detected by the library (Python: RequestError, ValueError).

For example: a NULL request, argument or output pointer, a missing model, a message without role, an image with neither path, data nor base64, an array count without its array, an invalid header, a missing API key for web search, an invalid OLLAMA_HOST or OLLAMA_API_KEY when the default client is created, or the wrong ollama_stream_next_*() function for a stream. Each function lists its own cases.

OLLAMA_ERROR_RESPONSE 

The server answered with an HTTP error status, or sent an error in the middle of a stream (Python: ResponseError).

The message is the server's error text (see ollama_error_t::message).

OLLAMA_ERROR_CONNECTION 

The server could not be reached: connection refused, host or proxy name not resolved (Python: ConnectionError).

OLLAMA_ERROR_TRANSPORT 

Any other network failure: timeout, TLS error, interrupted transfer, too many redirects.

OLLAMA_ERROR_PARSE 

The server sent an answer, or a line of a stream, that is not valid JSON.

OLLAMA_ERROR_IO 

A local file (image, blob) could not be read.

OLLAMA_ERROR_MEMORY 

Out of memory.

Also reported when the default client cannot be created for another reason than an invalid OLLAMA_HOST or OLLAMA_API_KEY (OLLAMA_ERROR_REQUEST), such as a failure to initialize libcurl.
