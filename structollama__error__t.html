Detailed Description

Details of an error (Python: the attributes of the exception).

Returned by ollama_last_error() and ollama_stream_error(). The struct belongs to the client or stream it comes from: copy what you need before the next call on it.

const char* ollama_error_t::message

Human readable reason, never NULL: "" on success.

For OLLAMA_ERROR_RESPONSE it is the "error" string of the server's JSON answer (Python: ResponseError.error); otherwise, including JSON without a string "error" member, the raw answer (up to its first NUL byte); or "HTTP " followed by the status code when the answer is empty.
