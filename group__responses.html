Detailed Description

Results of the API calls, one struct per response model of the Python library.

Responses are allocated by the library and belong to the caller, who releases them with ollama_response_free(). All the strings, arrays and JSON values they point to live exactly as long as the response: copy them (ollama_json_copy(), ollama_messages_add_message(), ...) to keep them longer. The parts of a stream are the exception: they belong to the stream.

Fields missing from the answer of the server are NULL (strings, arrays, JSON values), 0 or false, unless noted otherwise. Arrays come with a _count field, and the pointer may be NULL when the count is 0. Every response has a json field with the whole answer as sent by the server, never NULL, to read fields that this version does not know (Python: ‘response['field’]`).

Durations are in nanoseconds, sizes in bytes, and dates are the ISO 8601 strings sent by the server.

void ollama_response_free ( void *  response)

Releases a response returned by one of the API functions, with everything it points to.

It works for every response type. Do not call it on the parts returned by the ollama_stream_next_*() functions: they belong to their stream.
