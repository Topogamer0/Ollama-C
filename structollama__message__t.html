Detailed Description

A chat message, used both in requests and in responses (Python: ollama.Message).

In requests only role is required, and NULL or empty strings are not sent, like _copy_messages() in the Python client. In responses content is never NULL, the other strings are NULL when absent and images is always NULL.

ollama_message_t messages[] = {
{.role = "system", .content = "Answer in one sentence."},
{.role = "user", .content = "Why is the sky blue?"},
};
ollama_chat_request_t req = {.model = "gemma3", .messages = messages, .messages_count = 2};
