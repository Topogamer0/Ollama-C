Detailed Description

An image for multimodal models (Python: the items of images=[...]).

Set exactly one of path, data or base64; if several are set, base64 wins over path, which wins over data. The file is read, and the data encoded, when the request is sent. Images only appear in requests: messages of responses never carry images.

ollama_image_t images[] = {{.path = "cat.jpg"}, {.data = bytes, .size = n}, {.base64 = encoded}};
ollama_message_t msg = {.role = "user", .content = "Compare them", .images = images, .images_count = 3};
