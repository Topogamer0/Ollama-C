Detailed Description

One blocking function per method of the Python client.

All the functions follow the same rules:

  • client is the client to use, or NULL for the default client (see Client).
  • Requests are only read during the call.
  • The result is stored in *response (*digest for ollama_create_blob()), which is set to NULL first and stays NULL on failure. On success it belongs to the caller: release it with ollama_response_free() (ollama_free() for the digest).
  • The function returns OLLAMA_OK or an error code, and the details of the error are available from ollama_last_error(client) until the next call on the client.

Besides the checks of the arguments described for each function, every call can fail with:

  • OLLAMA_ERROR_CONNECTION: the server cannot be reached (connection refused, unknown host or proxy). The message is the one of ollama-python, "Failed to connect to Ollama. Please check that Ollama is downloaded, running and accessible. https://ollama.com/download".
  • OLLAMA_ERROR_TRANSPORT: any other network failure, such as a timeout (see ollama_client_set_timeout()), a TLS error, an interrupted transfer or too many redirects; the message comes from libcurl.
  • OLLAMA_ERROR_RESPONSE: the server answered with an HTTP status outside 200-299, which is stored in ollama_error_t::status_code; the message is the "error" field of the JSON answer (see ollama_error_t::message).
  • OLLAMA_ERROR_PARSE: the answer is not valid JSON (only for the calls that return a response).
  • OLLAMA_ERROR_MEMORY: out of memory.
  • With a NULL client, when the default client cannot be created: OLLAMA_ERROR_REQUEST if OLLAMA_HOST or OLLAMA_API_KEY is invalid, OLLAMA_ERROR_MEMORY otherwise. Nothing is sent and ollama_last_error(NULL) gives the reason.

Redirects are followed, as with follow_redirects=True in the Python client.

Uploads a file as a blob (POST /api/blobs/sha256:...; Python: create_blob()).

The file is read twice: once to compute its SHA-256 digest, then to upload it, so it must not change during the call. The digest identifies the blob in the files and adapters of ollama_create_request_t.

char *digest;
if (ollama_create_blob(client, "model.gguf", &digest) == OLLAMA_OK) {
ollama_json_t *files = ollama_json_object();
ollama_json_set_string(files, "model.gguf", digest);
ollama_free(digest);
ollama_create_request_t req = {.model = "my-model", .files = files};
// ... ollama_create(client, &req, &res) ...
ollama_json_free(files);
}
