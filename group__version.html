Macro Definition Documentation

◆ OLLAMA_C_VERSION

#define OLLAMA_C_VERSION   "0.2.1"

Version of this header as a string, "MAJOR.MINOR.PATCH".

Compare it with ollama_version() to detect an application compiled against a different header than the library it runs with.

◆ OLLAMA_API

#define OLLAMA_API

Marks the functions exported by the library.

It expands to __declspec(dllexport) on Windows while the library itself is built as a DLL (the build defines OLLAMA_BUILDING_DLL), otherwise to __attribute__((visibility("default"))) with GCC 4 or later and compatible compilers such as Clang, and to nothing with other compilers. Applications do not need to define anything.

◆ ollama_version()

const char * ollama_version ( void  )

Returns the version of the compiled library, such as "0.2.0".

It can differ from OLLAMA_C_VERSION, the version of the header the application was compiled with, when the application runs with another build of a shared library.

Returns
A static NUL-terminated string; do not free it.
