Detailed Description

Ollama-C: C client library for Ollama, a port of ollama-python.

A C port of the official Python library (https://github.com/ollama/ollama-python). Every function of the Python Client has a C counterpart with the same name:

Python C
ollama.generate(model=..., prompt=...) ollama_generate(client, &req, &res)
ollama.chat(model=..., messages=...) ollama_chat(client, &req, &res)
ollama.chat(..., stream=True) ollama_chat_stream(client, &req, &stream)
ollama.embed / embeddings ollama_embed / ollama_embeddings
ollama.pull / push / create ollama_pull / ollama_push / ollama_create
ollama.list / show / ps ollama_list / ollama_show / ollama_ps
ollama.copy / delete / create_blob ollama_copy / ollama_delete / ollama_create_blob
ollama.web_search / web_fetch ollama_web_search / ollama_web_fetch
ollama.systemone ollama_systemone

Conventions:

  • Functions that return an ollama_status_t return OLLAMA_OK (0) on success or an error code (see Errors); for the calls that take a client, details about the last error are available from ollama_last_error(). Functions that return a pointer report a failure with NULL; those that take neither a client nor a stream (ollama_client_new(), the JSON functions, the helpers) record no error details.
  • Passing NULL as the client uses a default client, configured from OLLAMA_HOST like the module-level functions of the Python library (ollama.chat(...)). The default client is not thread-safe and is released by ollama_cleanup() (see Client).
  • Request structs only borrow the memory they point to (see Requests).
  • Responses are allocated by the library and released with ollama_response_free(). Their strings and arrays live as long as the response itself (see Responses).
  • Optional string fields are NULL when absent. Optional numbers are 0 when absent.
  • Strings are NUL-terminated UTF-8; the library does not validate the encoding. File paths are the exception: they are passed to fopen() unchanged, so on Windows they are in the active code page, like the arguments of main().
