Detailed Description

A tool call requested by the model (Python: Message.ToolCall).

Responses fill it from the answer of the model. In requests it sends back the calls of an assistant message of the history, a NULL name being left out and NULL arguments sent as an empty object.

Arguments, normally a JSON object read with ollama_json_get().

Its type is not checked, either in responses (the "arguments" value of the answer as it is, NULL if missing) or in requests (sent as it is). In responses it belongs to the response.
